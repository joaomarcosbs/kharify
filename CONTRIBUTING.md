# Contributing

## Running locally

Follow the Docker or local development setup in [README.md](README.md). Before opening a pull request, run the relevant API tests, web lint, and production builds.

## Pull requests

1. Keep changes scoped and explain the user-facing impact.
2. Run the relevant API tests, web lint, and production builds.
3. Do not include secrets, private financial data, generated credentials, or local environment files.
4. Update the README or application-specific README files when behavior or configuration changes.

The contributor agreement (CLA) is still being defined. External contributions will only be accepted after it has been established.
